# Shared Data — ข้อมูลที่ใช้ร่วมกันระหว่างแผนก

## Files
- `icp.md` — Ideal Customer Profile
- `niche.md` — กลุ่มเป้าหมาย
- `leads.md` — leads จาก Sales
- `posts.md` — posts จาก Marketing
- `report.md` — รายงานจาก Finance
- `daily-plan.md` — แผนงานประจำวันจาก Ops
- `findings.md` — ผลการวิจัยจาก Research
- `tasks.json` — task queue
- `topics.md` — หัวข้อวิจัย
- `support-summary.md` — สรุปสถานะ support

## Rules
- ทุกแผนกสามารถอ่าน shared/ ได้
- เขียน shared/ ได้เฉพาะเมื่อจำเป็น (เช่น Sales เขียน leads.md)
- ห้ามลบหรือแก้ไขไฟล์ shared ของแผนกอื่น
